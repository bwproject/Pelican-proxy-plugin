# BW Proxy & AmneziaWG for Pelican

Плагин для панели Pelican: настройки исходящего SOCKS5-прокси с авторизацией или режима AmneziaWG.

## Важно: граница ответственности

**Плагин панели не может сам по себе перенаправить сетевой трафик уже запущенных игровых контейнеров.** SOCKS5 — прикладной прокси: процесс должен поддерживать SOCKS5 или запускаться через совместимый wrapper (например, proxychains-ng). Это не универсальный прозрачный туннель для любого UDP/TCP-трафика.

AmneziaWG — VPN-интерфейс на узле. Чтобы трафик конкретного контейнера шёл через него, требуется отдельно настроить сетевую маршрутизацию/namespace на узле Pelican/Wings и правила firewall. Нельзя безопасно включать это одним только изменением .env панели.

## Возможности текущей версии

- Страница настроек администратора Pelican.
- Выбор: отключено / SOCKS5 / AmneziaWG.
- SOCKS5 host, port, username и password.
- Имя уже поднятого интерфейса AmneziaWG (по умолчанию `awg0`).
- Проверка базовых значений и сохранение параметров с префиксом `BWPROXY_` в .env панели.

## Установка

1. Скачайте ZIP-архив `bwproxy.zip` из GitHub Releases.
2. В панели Pelican откройте Plugins → Import и загрузите архив.
3. Нажмите Install.
4. Откройте настройки **BW Proxy & AmneziaWG**.

Для ручной установки поместите папку `bwproxy` в `/var/www/pelican/plugins` и выполните из каталога панели:

```bash
php artisan p:plugin:install
```

## Что требуется для полноценного перенаправления

### SOCKS5

- Узел должен иметь сетевой доступ к SOCKS5-серверу.
- Нужно настроить запуск целевого приложения/контейнера через SOCKS5-совместимый wrapper либо использовать поддержку прокси в самом приложении.
- Проверьте отдельно DNS, TCP и UDP: обычный SOCKS5 wrapper не гарантирует поддержку UDP и всех игровых протоколов.
- Не публикуйте SOCKS5-пароль в логах, командной строке или Git.

### AmneziaWG

- Сначала установите и поднимите AmneziaWG на узле.
- Затем настройте изоляцию маршрутов для нужного контейнера (network namespace / отдельная Docker-сеть с VPN gateway) и защиту от утечки трафика при падении туннеля.
- Не меняйте глобальный default route хоста без проверки доступа к Pelican, SSH и Wings.

## Безопасность и ограничения

Учётные данные сохраняются в `.env` панели в виде переменных `BWPROXY_*`. Защитите файл правами доступа и резервными копиями. Плагин не проверяет доступность прокси и не меняет сетевые правила хоста. Текущая версия — панель настроек, а не автоматический сетевой агент.
